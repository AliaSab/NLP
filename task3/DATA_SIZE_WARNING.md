# ⚠️ Предупреждение о размере данных

## Проблема

Текущие выборки очень малы:
- **Train**: 5 статей
- **Validation**: 0 статей  
- **Test**: 3 статей

## Причины

1. **Мало исходных данных**: В файле `kommersant_articles_processed.jsonl` всего **2000 статей**
2. **Агрессивная балансировка**: Функция `balance_classes` ограничивает дисбаланс до 3:1, что для малых выборок приводит к потере данных
3. **Фильтрация коротких текстов**: Тексты короче 10 слов отбрасываются

## Решения

### Вариант 1: Увеличить исходный корпус (РЕКОМЕНДУЕТСЯ)

Запустите парсер из Task1 снова, чтобы собрать больше статей:

```bash
cd NLP/Task1
python kommersant_parser.py  # или universal_news_parser.py
```

Цель: собрать **не менее 10000-20000 статей** для качественного обучения.

### Вариант 2: Отключить балансировку для малых выборок

Если данных мало, можно временно отключить балансировку или сделать её менее агрессивной. 
Уже исправлено в коде: для выборок < 100 образцов используется соотношение 5:1 вместо 3:1.

### Вариант 3: Использовать все доступные данные

Можно временно использовать все 2000 статей без балансировки для получения большего количества данных.

## Текущее состояние

После исправлений:
- Балансировка стала менее агрессивной для малых выборок
- Validation выборка теперь гарантированно содержит данные
- Добавлены предупреждения о недостаточном количестве данных

## Рекомендации

1. **Соберите больше данных** - это самое важное
2. Перезапустите `prepare_corpus.py` после сбора данных
3. Проверьте размеры выборок командой: `python check_corpus.py`

## Минимальные требования

Для качественного обучения рекомендуется:
- **Train**: не менее 1000-2000 образцов
- **Validation**: не менее 200-300 образцов  
- **Test**: не менее 200-300 образцов

Текущие размеры (5/0/3) недостаточны для достоверной оценки моделей.
